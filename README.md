# 4반 백과

GitHub Pages용 간단한 4반 백과사전 사이트입니다.

## 중요한 점: "나만 올릴 수 있게" 하기

이 사이트는 **GitHub 저장소를 Public으로 두고 GitHub Pages로 공개**하는 방식입니다.

- 친구: 사이트를 볼 수 있음
- 관리자(나): GitHub 저장소에 로그인해서 파일을 수정/추가
- 친구: GitHub 저장소의 수정 권한이 없으므로 직접 문서를 올릴 수 없음

### 주의
문서 추가 요청은 현재 `index.html`의 `YOUR_EMAIL@example.com`을 본인의 이메일 주소로 바꿔야 합니다.

또한 GitHub 저장소에서 **Settings → Collaborators**에 친구를 추가하지 마세요. 추가하면 친구에게 저장소 수정 권한을 줄 수 있습니다.

## GitHub Pages 설정

Repository → Settings → Pages → Deploy from a branch → `main` / `/ (root)` → Save
